# パネマジ 独自MECEエリア定義 (v5b)

**このドキュメントが唯一の正**。外部ソース (シティヘブン・男性用メンエス情報サイト・駅ちか・ぴゅあらば等) のエリア区分はここにマップする。
新規追加・統合・分割は **必ず `scripts/lib/unified-areas.mjs` と本ドキュメントを1コミットで同期** すること。

## 原則

1. **ME (Mutually Exclusive)** — 同一エリアは1つのスロットにのみ割り当て (重複禁止)
2. **CE (Collectively Exhaustive)** — 必要な都道府県に「○○その他」枠 (order=99) を置き、マッピング漏れを拾う
3. **0店舗のエリアは作らない / 残さない** — migrate-areas-mece.mjs が空エリアを削除する
4. **slug は英小文字+ハイフンのみ** — 日本語混入禁止 (`fukuiその他` ❌ → `fukui-other` ✅)
5. **キーワードは長いものを優先** — pickArea() は `score = kw.length * 2` で比較 (strict-greater)
6. **同pref内のキーワード重複禁止** — 検証スクリプトで0件であることを担保

## 全体規模

- **47都道府県 / 325エリア** (v5b: 2026-05-04 確定)
- v4 → v5b: SEO long-tail 対応で札幌/大阪/東京/愛知/兵庫/福岡等の主要都市を細分化
- **増減はユーザー承認 + docs同時更新が絶対条件**
